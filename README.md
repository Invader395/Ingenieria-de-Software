# Minimarket Control

**Autor:** Julián Guerrero Martínez

---

**¿Qué hace?** Es un programa que te proporciona información sobre el inventario en estantes, registra los costos reales de cada producto con sus distintos proveedores y registra las ventas diarias por empleado. Adicionalmente gestiona los encargos para entrega rápida y recompensa a los clientes frecuentes con puntos por compra.
