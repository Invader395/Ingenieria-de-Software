# Minimarket Control

---

**Autor:** Julián Guerrero Martínez  
**¿Qué hace?** Programa que da control total del inventario en estantes, registra los costos reales de cada proveedor y administra tus ventas diarias al instante. Además, identifica qué empleado realiza cada cobro, gestiona encargos para entrega rápida y premia a tus clientes frecuentes con un programa de puntos.
